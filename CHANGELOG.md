# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - Initial Release

### Added
- **Workflow Builder**: Interactive ReactFlow-based canvas for designing pipelines.
- **Templates**: CI/CD, Data ETL, and AI Triage starter templates.
- **Backend Execution Engine**: Spring Boot orchestrator with Kafka event streaming.
- **Monitoring Hub**: Live dashboard with active run tracking and execution status.
- **Security**: JWT authentication and Role-Based Access Control skeleton.
- **Infrastructure**: Full Docker Compose setup for Postgres, Redis, Kafka, Prometheus, and Grafana.
- **Kubernetes**: Included baseline K8s manifests for deployments.
